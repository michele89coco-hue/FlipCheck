# FlipCheck Native v1.01

- Seconda lettura visiva selettiva e senza Web Search quando una carta o una box presenta
  molti segnali fisici ma la prima risposta omette campi necessari dalla tupla identitaria.
- La seconda lettura parte soltanto se il costo della prima richiesta più la riserva prevista
  resta entro 0,02 dollari; non parte per telecomandi o oggetti generici senza codice.
- Recupero universale per carte: produttore/set, soggetto, numero, parallel, rookie, finitura
  e assi di stampa/edizione vengono riletti direttamente dalla foto, senza usare ipotesi web.
- Recupero universale per box: produttore, stagione, linea esatta, sport, formato e
  configurazione stampata vengono riletti direttamente dal fronte.
- Il modello finale delle carte sportive conserva sempre il soggetto/giocatore osservato.
- Una tupla completa stampata sulla box prevale sui candidati web generici non esatti.
