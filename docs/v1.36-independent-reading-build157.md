# Build157: independent reading and field semantics

The supplied kobe.json is a build156 PHOTO_READ run, not the earlier CONFLICTED screenshot. It contains one Vision and zero Web calls costing $0.00143976. Vision returned METAL UNIVERSE at a front emblem, a SkyBox maker logo, copyright 1997, athlete height/weight transported as hp, and a low-confidence 46/74 number. The generic OCR context sent to Vision included repeated rotated phone UI and corrupted 4G/74 text. This is a plausible anchoring source, not proof of causation. Existing project reference photos visibly show 81 on the back and 97-98 in the front wordmark, but those values are absent from the recorded Vision response.

The source ZIP is v1.25 (versionCode128). Its hierarchical reading/identity split is useful; many modules are already in the repository. This build does not replace the whole engine with that legacy tree.

Changes:
- Initial Vision reads the images independently, without injected raw local OCR. OCR remains available as separately attributed evidence. The prompt prioritizes every face, corners, product wordmarks and identifiers over statistics, and excludes phone UI.
- A high-confidence, explicitly named product-line wordmark at a logo/emblem no longer requires duplicate OCR. Symbol-family guesses remain inferred.
- A named maker-logo physicalFeature can derive a separate brand atom only with the correct maker role and matching local text. Copyright owners, league marks and graders cannot take this path.
- Sports height/weight is playerMeasurements; a year located on a copyright line is copyrightYear. Single-year copyright text normalizes without inventing a release season.
- Photo reading composes the title from stable observed brand, line, subject and sufficiently confident number. Uncertain numbers are labelled for re-reading, not silently promoted. Foil alone does not confirm the parallel in photo mode.
- Photo results retain stable readings when other fields conflict. The contradictory field/value pairs remain explicit and cannot close identity or enter the market. Such complete photo readings can resume Web/Vision/Web without repaying Vision1.

Tests use the actual recorded response and local OCR. They assert that 46/74 remains uncertain and is never replaced by 81. A separate explicitly changed high-confidence response tests display of a properly read 81; it is a synthetic behavior test, not a new Vision result. No paid API scan, Android installation or improvement in live OCR accuracy is claimed.
