## Live diagnostics changes

- Store report in target app-private files; export via `adb exec-out run-as` instead of
  inaccessible external-storage `adb pull`.
- Persist each completed run, including failures.
- Record result data and screenshot before evaluating recognition expectations.
- Record hashes and byte lengths of actual test inputs.
- Include observed, inferred, retrieved, candidate, rejected-source and crop traces.
- Redact the configured API credential from failure messages.

The test harness injects neutral input URIs through the existing debug import path,
then uses the actual foreground service, OCR and production API client. This exercises
preview, service, result store and rendering, but does not automate the system document
picker. The recompressed mode is test-created JPEG quality 76 before normal app
preprocessing; it is not an independently captured copy of the app's encoder output.
