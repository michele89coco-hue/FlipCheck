# FlipCheck Native v1.05

- Aggiunto recovery catalogo obbligatorio per qualsiasi carta informativa rimasta
  aperta dopo la prima ricerca, anche quando il torneo restituisce zero candidati.
- Il secondo passaggio riparte dai dati fisici e non eredita la shortlist fallita.
- Le carte sportive possono essere chiuse senza numero carta stampato quando il
  confronto esatto fronte/retro, soggetto, set/anno e almeno cinque segnali
  distintivi convergono su una sola voce di catalogo.
- Le diciture commerciali `TRADING CARD GAME` su prodotti sportivi (per esempio
  Adrenalyn XL) non trasformano più la carta in una TCG e non attivano l’obbligo
  errato del numero collezione.
- Il secondo passaggio usa una sola Web Search e rispetta il tetto previsto di
  0,025 USD per scansione.
- Nessun giocatore, set o carta è codificato nella logica.
